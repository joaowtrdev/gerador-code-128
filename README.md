# Gerador Code 128 em Lote

Aplicação web para transformar uma lista de valores em códigos de barras no padrão Code 128, diretamente no navegador.

## Objetivo

O projeto tem como objetivo facilitar a geração e a consulta de códigos de barras a partir de uma lista, evitando a necessidade de digitar cada valor separadamente. O usuário pode carregar até 10.000 códigos e navegar entre eles, visualizando um código de barras por vez.

A ferramenta pode apoiar tarefas de identificação e conferência de produtos, itens de estoque e outros registros que utilizem códigos de barras.

## Funcionalidades

- Entrada de múltiplos códigos, com um valor por linha.
- Limite configurável de até 10.000 códigos por lista.
- Remoção de linhas vazias e espaços no início e no fim de cada valor.
- Visualização do código de barras e do texto correspondente.
- Navegação pelos botões de anterior e próximo ou pelas setas do teclado.
- Acesso a uma posição específica da lista pelo campo **Ir para**.
- Ajustes de escala, altura das barras, tamanho do texto e margem branca.
- Opção de regerar o código atual após alterar as configurações.
- Contador da posição atual, mensagens de status e indicação de erros de geração.
- Botão para limpar a lista e a visualização.

## Como usar

Para utilizar o gerador, acesse o site: [Gerador Code 128](https://joaowtrdev.github.io/gerador-code-128/).
